# Masterwood Project 4005L – Fusion post processor (MW310 / Syncro)

**Status: unfinished, work in progress.** Nothing here is an official release until it reaches a usable state. Do not run it on a machine without checking every program yourself.

Fusion (Autodesk) post processor and machine/fixture setup for a Masterwood Project 4005L 5-axis CNC with an MW310 control: native 3+2 tilted machining (G172/G173), automatic program naming, fast linking via home, and a rails + vacuum-pod machine model for Fusion's machine simulation.

- `masterwood_4005L.cps` – the post
- `fork-*` – experimental work (drilling, fixtures/pods, naming, linking)
- `samples/` – reference MW310 programs

Want to use it or contribute? Please contact us first by opening an issue on this repo.
